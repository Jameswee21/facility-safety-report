# 시설 보수 신고 및 안전 건의 홈페이지

모바일 전용으로 설계된 정적 웹사이트입니다. 서버 코드 없이 HTML/CSS/JS 파일만으로 동작하므로
무료 호스팅 서비스에 그대로 올려서 운영할 수 있습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 구조 (신고화면 / 신고내역·처리현황 / 안전 건의함) |
| `style.css` | 모바일 전용 디자인 |
| `app.js` | 앱 동작 로직 |
| `config.js` | **설정 파일 — 관리자 코드, Supabase 키를 여기서 수정** |
| `storage.js` | 데이터 저장 계층 (데모 모드 / Supabase 모드 자동 전환) |
| `supabase-setup.sql` | Supabase 데이터베이스 초기 설정 SQL |

## 주요 기능

- **신고화면**: 신고유형(4종) → 발생위치 → 발생일시 → 상황설명 → 사진첨부(필수, 자동 압축) → 연락처(선택)
  - 연락처를 입력하면 개인정보 수집·이용 동의 화면이 나타나고, 동의해야 제출 버튼이 활성화됩니다.
  - 연락처가 없으면 동의 절차 없이 바로 제출할 수 있습니다.
- **신고내역 확인 및 처리현황**: 발생일시 / 발생위치 / 점검사항(상황설명·사진) / 담당자 / 조치일 / 상태(진행중·조치완료)
  - 우측 상단 **관리자** 버튼 → 관리자 코드 입력 → 담당자 지정 가능
  - 상세 화면에서 "진행중" 옆 체크박스를 체크하면 **조치완료**로 바뀌고 **조치일이 자동 입력**됩니다.
- **안전 건의함**: 간단한 게시판 (제목/내용/작성자-익명 가능)

## 두 가지 운영 모드

### 1) 데모 모드 (기본값 — 설정 없이 바로 동작)
`config.js`의 Supabase 값이 비어 있으면 데이터가 **접속한 기기(브라우저)에만** 저장됩니다.
화면·기능 확인용이며, 여러 사람이 함께 쓰는 실제 운영에는 적합하지 않습니다.

### 2) 운영 모드 (Supabase 무료 플랜 — 여러 사람이 데이터 공유)
Supabase는 무료 플랜(신용카드 불필요)으로 DB 500MB + 파일 저장소 1GB를 제공합니다.

1. https://supabase.com 에서 GitHub 계정으로 가입 → **New Project** 생성 (region: Northeast Asia/Seoul 권장)
2. 대시보드 왼쪽 **SQL Editor** → `supabase-setup.sql` 내용 전체 붙여넣기 → **Run**
3. **Project Settings → API** 에서 두 값을 복사:
   - `Project URL` → `config.js`의 `supabaseUrl`
   - `anon public` 키 → `config.js`의 `supabaseAnonKey`
4. 수정한 파일을 다시 배포하면 끝. 이후 모든 신고·건의가 공유 DB에 저장됩니다.

> ⚠️ 무료 플랜은 **1주일간 접속이 없으면 프로젝트가 일시정지**됩니다.
> 대시보드에서 클릭 한 번으로 재개할 수 있으며, 주기적으로 사용하면 정지되지 않습니다.

## 무료 배포(호스팅) 방법

정적 사이트라서 아래 서비스 모두 무료입니다. 가장 쉬운 순서로:

### 방법 A — Netlify Drop (가장 쉬움, 계정만 있으면 1분)
1. https://app.netlify.com/drop 접속 (무료 가입)
2. `homepage` 폴더를 브라우저 창에 **드래그 앤 드롭**
3. 생성된 주소(예: `https://xxxx.netlify.app`)를 직원들에게 공유
4. 파일을 수정하면 같은 화면에 다시 드래그하여 갱신

### 방법 B — GitHub Pages
1. GitHub 저장소 생성 → `homepage` 폴더의 파일 업로드
2. Settings → Pages → Branch를 `main`으로 선택 → Save
3. `https://<아이디>.github.io/<저장소이름>/` 주소로 접속

### 방법 C — Vercel / Cloudflare Pages
GitHub 저장소를 연결하면 파일 수정 시 자동으로 재배포됩니다.

## 계정 체계 (3단계)

| 계정 | 초기 비밀번호 | 권한 |
|---|---|---|
| 마스터 | `config.js`의 `masterCode` | 전체 기능 + 신고/건의 삭제 + 아래 두 계정 비밀번호 변경 |
| 시설팀장 | 2026 | 담당자 지정, 조치완료, 카톡 메시지, CSV, 연락처 열람 |
| 담당자(공용) | 1111 | 처리현황 열람 + 조치완료 체크만 |

- 시설팀장/담당자 비밀번호는 마스터로 로그인 후 대시보드의 **🔐 비밀번호 관리**에서 변경합니다.
- 기존 운영 DB에는 `supabase-accounts.sql`을 SQL Editor에서 한 번 실행해야
  비밀번호 변경과 삭제 기능이 동작합니다. (신규 설치는 `supabase-setup.sql`에 포함)

## 보안 주의사항

- `config.js`의 **`masterCode`를 반드시 변경**하세요.
- 계정 인증은 간이 인증(브라우저 측 확인)입니다. 원내 직원용 간이 시스템 수준이며,
  외부 공개 사이트에 민감정보를 다루는 용도로는 별도의 로그인 체계가 필요합니다.
- 신고 데이터에 연락처가 포함되므로, 사이트 주소는 원내 직원에게만 공유하는 것을 권장합니다.
